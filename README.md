# Оптимизация выдачи конференций

Серверный программный модуль для информационной системы анализа научной деятельности (ИСАНД).

## Описание

Модуль решает задачу агрегированного представления конференций:  
конференции с одинаковым базовым названием («УБС-2023», «УБС-2024» и т.д.)
объединяются в **серию** с сохранением доступа к каждому отдельному выпуску.

## Структура проекта

```
conference_optimizer/
├── main.py          # точка входа, CLI
├── normalizer.py    # алгоритм нормализации названий
├── grouper.py       # алгоритм группировки в серии
├── api_client.py    # клиент REST API ИСАНД v2.5
├── csv_loader.py    # загрузка тестовых данных из CSV
├── models.py        # модели данных (Conference, ConferenceSeries)
├── tests/
│   ├── test_normalizer.py
│   └── test_grouper.py
├── data/
│   └── conferences_with_publications.csv
└── requirements.txt
```

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
# Запустить с данными из CSV
python main.py --source csv

# Подробный вывод с выпусками
python main.py --source csv --verbose --limit 10

# Режим «как сейчас» (без группировки — регрессионный тест)
python main.py --source csv --legacy

# Сохранить результат в JSON
python main.py --source csv --export result.json

# Демонстрация алгоритма нормализации
python main.py --demo-normalize

# Запрос к API ИСАНД
python main.py --source api --query "управление"

# Статистика по CSV
python main.py --stats
```

## Тесты

python -m pytest tests/ -v

## Алгоритм

### Нормализация названий (`normalizer.py`)

1. Очистка строки от лишних пробелов
2. Поиск и выделение года (4-значное число 1900–2099)
3. Выделение локации (город/страна в скобках или после запятой)
4. Удаление года и служебных суффиксов из базового названия
5. Финальная нормализация разделителей и пробелов

### Группировка в серии (`grouper.py`)

После нормализации конференции группируются по `base_name`.  
Поддерживается нечёткое сравнение (расстояние Левенштейна) для
устойчивости к опечаткам (порог схожести: 0.85).

## REST API ИСАНД

Документация: `http://193.232.208.28/api/v2.5/`  
Модуль использует эндпоинт `GET /api/v2.5/conferences/search`.
